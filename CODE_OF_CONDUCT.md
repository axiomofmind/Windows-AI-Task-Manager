# Contributor covenant code of conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background, identity, experience, or level of technical expertise.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on code, behavior, evidence, and safety.
- Accept responsibility for mistakes and correct them.
- Protect private information and security reports.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disclosure of private information, and unsafe or malicious contributions are not acceptable.

## Enforcement

Project maintainers may remove content or participation that violates these expectations. Until a dedicated conduct address is configured, report incidents privately through the [repository owner's GitHub profile](https://github.com/axiomofmind); do not put private incident details in a public issue.
